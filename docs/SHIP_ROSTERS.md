# Ship name roster

Personal-use project: the owner does not intend to distribute this game. Setting-inspired names and imagery are for that private game.

480 authored names: ten per player combat class, ten per opposing combat class, ten shared civilian names and ten station names for each of four themes. Civilian names apply to any civilian ship, regardless of hull class or function. Classes are cosmetic aliases of five fixed balance tiers. Several class terms and all name pools are creative additions rather than a claim of a complete canonical fleet taxonomy. The Culture example **A Measure of Effort** is included.
